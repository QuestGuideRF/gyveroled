# GyverOLED

Лёгкая и быстрая библиотека для работы с OLED дисплеями на чипах SSD1306 и SSH1106 с разрешением 128×64 и 128×32 пикселей. Поддерживает подключение по интерфейсам I2C и SPI, предоставляет гибкие настройки буферизации и богатый набор функций для вывода текста и графики.

## ✨ Особенности

- **Поддержка различных дисплеев**: SSD1306 (128×64, 128×32) и SSH1106 (128×64)
- **Гибкая буферизация**:
  - Режим без буфера (экономия памяти)
  - Буфер на стороне микроконтроллера (удобство работы)
  - Выборочное обновление областей буфера
  - Динамический буфер произвольного размера
- **Быстрый вывод текста**:
  - Поддержка русского языка и буквы ё
  - 4 размера шрифта (1×, 2×, 3×, 4×) на базе одного шрифта
  - Попиксельная адресация для точного позиционирования
  - Полноэкранный вывод с автоматическим удалением лишних пробелов
  - Инверсия текста (чёрный на белом / белый на чёрном)
- **Управление дисплеем**:
  - Настройка яркости
  - Быстрая инверсия всего дисплея
  - Включение/выключение из кода
  - Зеркальное отображение по вертикали и горизонтали
- **Графические примитивы**:
  - Точки, линии (включая быстрые горизонтальные и вертикальные)
  - Прямоугольники (обычные и со скруглёнными углами)
  - Окружности
  - Кривые Безье
  - Режимы отрисовки: заливка, контур, очистка
- **Работа с изображениями**:
  - Вывод битмапов в любую точку дисплея
  - Вывод за пределы видимой области (для прокрутки)
  - Инверсия битмапов
- **Интерфейсы подключения**: I2C и SPI
- **Совместимость**: Работает со всеми платформами Arduino

## 🚀 Быстрый старт

### Установка

#### Через менеджер библиотек

Библиотеку можно установить через менеджер библиотек в:
- Arduino IDE
- Arduino IDE v2
- PlatformIO (поиск: `GyverOLED`)

#### Ручная установка

1. Скачайте библиотеку в формате `.zip` архивом
2. Распакуйте архив
3. Скопируйте папку в директорию библиотек Arduino:
   - Windows (x64): `C:\Program Files (x86)\Arduino\libraries\`
   - Windows (x32): `C:\Program Files\Arduino\libraries\`
   - Альтернативно: `Документы/Arduino/libraries/`
4. Перезапустите Arduino IDE

**Или** используйте автоматическую установку из `.zip`:
- В Arduino IDE: `Скетч` → `Подключить библиотеку` → `Добавить .ZIP библиотеку…` → выберите скачанный архив

### Инициализация

```cpp
#include <GyverOLED.h>

// I2C подключение
GyverOLED<SSD1306_128x32, OLED_BUFFER> oled;        // 128×32 с буфером
GyverOLED<SSD1306_128x32, OLED_NO_BUFFER> oled;     // 128×32 без буфера
GyverOLED<SSD1306_128x64, OLED_BUFFER> oled;        // 128×64 с буфером
GyverOLED<SSD1306_128x64, OLED_NO_BUFFER> oled;     // 128×64 без буфера
GyverOLED<SSH1106_128x64> oled;                     // SSH1106 (только с буфером)

// Указание I2C адреса (по умолчанию 0x3C)
GyverOLED<SSD1306_128x64, OLED_BUFFER> oled(0x3C);

// SPI подключение
GyverOLED<SSD1306_128x64, OLED_BUFFER, OLED_SPI, CS, DC, RST> oled;
// где CS, DC, RST - номера цифровых пинов
// Дисплей подключается: D0 к SCK, D1 к MOSI
```

### Базовый пример

```cpp
#include <GyverOLED.h>

GyverOLED<SSD1306_128x64, OLED_BUFFER> oled;

void setup() {
  oled.init();      // Инициализация дисплея
  oled.clear();     // Очистка буфера
  oled.update();    // Обновление дисплея

  oled.home();      // Курсор в позицию (0, 0)
  oled.print("Hello, World!");
  oled.update();
}

void loop() {
  // Ваш код
}
```

### Настройка скорости I2C (опционально)

Для увеличения скорости обновления дисплея можно разогнать шину I2C:

```cpp
void setup() {
  oled.init();
  Wire.setClock(800000L);  // Максимальная частота 800 кГц
  // Внимание: не все другие I2C модули будут работать на такой частоте!
}
```

## 🛠 Использование

### Основные функции

#### Инициализация и сервис

```cpp
void init();                                    // Инициализация
void init(sda, scl);                            // Инициализация с указанием пинов I2C (для ESP8266/ESP32)
void clear();                                   // Очистить весь дисплей/буфер
void clear(int x0, int y0, int x1, int y1);    // Очистить область
void setContrast(uint8_t value);                // Яркость 0-255 (по умолчанию 127)
void setPower(bool mode);                       // Включить/выключить дисплей
void flipH(bool mode);                          // Зеркально отразить по горизонтали
void flipV(bool mode);                          // Зеркально отразить по вертикали
void invertDisplay(bool mode);                  // Инвертировать дисплей
```

#### Вывод текста

Библиотека наследует класс `Print`, поэтому поддерживает все стандартные функции `print()` и `println()`:

```cpp
void autoPrintln(bool mode);    // Автоматический перенос строк
void home();                    // Курсор в позицию (0, 0)
void setCursor(int x, int y);   // Курсор: столбец 0-127, строка 0-8(4)
void setCursorXY(int x, int y); // Курсор: пиксель X 0-127, пиксель Y 0-63(31)
void setScale(uint8_t scale);   // Масштаб шрифта (1-4)
void invertText(bool inv);      // Инвертировать текст
bool isEnd();                   // Проверка, достигнут ли конец дисплея
void textMode(byte mode);       // Режим отрисовки текста
```

Режимы отрисовки текста:
- `BUF_ADD` - наложить текст
- `BUF_SUBTRACT` - вычесть текст
- `BUF_REPLACE` - заменить (весь прямоугольник буквы)

Примеры:

```cpp
oled.home();
oled.print("Привет!");              // Обычный текст
oled.setScale(2);                    // Увеличить шрифт в 2 раза
oled.print("Большой текст");
oled.setCursorXY(10, 30);            // Точное позиционирование
oled.invertText(true);               // Инвертированный текст
oled.print("Инверт");
oled.autoPrintln(true);              // Автоперенос
oled.print("Длинный текст...");
```

// OLED_STROKE - обвести фигуру

void dot(int x, int y, byte fill = 1);                    // Точка

void fastLineH(int y, int x0, int x1, byte fill = 1);     // Горизонтальная линия
void fastLineV(int x, int y0, int y1, byte fill = 1);     // Вертикальная линия
void rect(int x0, int y0, int x1, int y1, byte fill = 1); // Прямоугольник
void roundRect(int x0, int y0, int x1, int y1, byte fill); // Скруглённый прямоугольник
void circle(int x, int y, int radius, byte fill);          // Окружность

Примеры:

```cpp
oled.dot(10, 10);                              // Точка
oled.line(0, 0, 127, 63);                      // Линия
oled.rect(10, 10, 50, 30, OLED_FILL);          // Залитый прямоугольник
oled.rect(10, 10, 50, 30, OLED_STROKE);        // Контур прямоугольника
oled.roundRect(20, 20, 60, 40, OLED_STROKE);   // Скруглённый прямоугольник
oled.circle(64, 32, 20, OLED_STROKE);          // Окружность
```

#### Работа с битмапами

```cpp
void drawBitmap(int x, int y, const uint8_t *frame, int width, int height,
                uint8_t invert = 0, byte mode = 0);
```

Параметры:
- `invert`: `BITMAP_NORMAL` (0) или `BITMAP_INVERT` (1)
- `mode`: `BUF_ADD`, `BUF_SUBTRACT` или `BUF_REPLACE`

Пример:

```cpp
const uint8_t bitmap_32x32[] PROGMEM = {
  // данные битмапа...
};

oled.drawBitmap(50, 16, bitmap_32x32, 32, 32, BITMAP_NORMAL, BUF_ADD);
```

### Настройки компиляции

Перед подключением библиотеки можно определить следующие макросы:

```cpp
#define OLED_NO_PRINT        // Отключить модуль вывода текста (экономит ~2.5 кБ Flash)
#define OLED_SPI_SPEED       // Скорость SPI (по умолчанию 1000000)
#define USE_MICRO_WIRE       // Использовать библиотеку microWire для ATmega328
```

### Работа с буфером

При использовании режима `OLED_BUFFER` все операции выполняются в буфере памяти, а на дисплей данные отправляются вызовом `update()`. Это позволяет:

- Быстро формировать сложные изображения
- Избежать мерцания при обновлении
- Использовать режимы наложения (`BUF_ADD`, `BUF_SUBTRACT`)

```cpp
oled.clear();           // Очистить буфер
// ... рисование ...
oled.update();          // Отправить буфер на дисплей
```

В режиме `OLED_NO_BUFFER` данные отправляются на дисплей сразу, что экономит память, но может быть медленнее для сложных изображений.

## 🔧 Технические детали

### Поддерживаемые дисплеи

- **SSD1306**: 128×64 и 128×32 пикселей
- **SSH1106**: 128×64 пикселей (только с буфером)

### Интерфейсы подключения

- **I2C**: стандартный интерфейс, адрес по умолчанию 0x3C
- **SPI**: требует указания пинов CS, DC и RST

### Требования к памяти

- **С буфером (128×64)**: ~1024 байт RAM
- **С буфером (128×32)**: ~512 байт RAM
- **Без буфера**: минимальное использование RAM

### Совместимость с SPI и SD картами

При одновременном использовании OLED дисплея по SPI и SD карты может возникнуть конфликт. Решение: после завершения работы с SD картой отпустите CS карты и отправьте несколько байт по SPI (например, пару нулей). Это связано с тем, что SD карта может удерживать линию данных.
